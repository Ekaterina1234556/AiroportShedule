## ✨ Основные возможности

| Модуль | Функционал |
|--------|------------|
| **✈️ Расписание** | Управление рейсами, отслеживание статусов (взлёт/посадка/задержка), фильтрация и сортировка |
| **👨‍✈️ Экипажи** | Учёт лётного и обслуживающего персонала, контроль налёта часов, опыта и сертификации |
| **🏭 Инфраструктура** | Визуализация схемы аэропорта: ВПП, ангары, терминалы, стоянки воздушных судов |
| **📦 Склады** | Учёт оборудования, припасов, технического имущества с возможностью контроля остатков |
| **🔧 ТО** | Планирование и учёт технического обслуживания воздушных судов и оборудования |
| **🔐 Авторизация** | Многоуровневая система доступа с разграничением прав по ролям персонала |

## 📊 Сущности системы

### 🧑‍✈️ Персонал
- **Лётный экипаж** — пилоты, штурманы, бортинженеры
- **Обслуживающий персонал** — техники, диспетчеры, наземный персонал
- **Администрация** — руководители, менеджеры

### ✈️ Воздушные суда
- **Типы самолётов** — пассажирские, грузовые, военные
- **Серийные номера** — уникальная идентификация ВС
- **Технические характеристики** — вместимость, дальность, вес

### 🏗️ Инфраструктура
- **ВПП (взлётно-посадочные полосы)** — номера, длина, покрытие, статус
- **Ангары** — вместимость, тип обслуживаемых ВС, занятость
- **Терминалы** — номера, пропускная способность
- **Стоянки** — позиции для парковки воздушных судов

### 📅 Рейсы
- **Номер рейса** — уникальный идентификатор
- **Маршрут** — пункт отправления и назначения
- **Время** — плановое и фактическое время вылета/прилёта
- **Статус** — ожидание, взлёт, в пути, посадка, задержан, отменён

### 📦 Ресурсы
- **Оборудование** — техника, инструменты, специальное оборудование
- **Припасы** — топливо, запчасти, расходные материалы
- **Инвентарь** — учёт имущества аэропорта
